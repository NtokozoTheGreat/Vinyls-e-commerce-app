VINYLS SHARED THEME ASSETS

Keep all newly generated/reference UI artwork for the redesigned pages in this folder:
    static/images/vinyls_theme/

Naming convention:
    home-...
    about-...
    record-collection-...
    record-store-...
    genre-...
    fresh-arrivals-...
    etc.

All new custom redesign CSS should be appended to:
    static/css/vinyls-theme.css

Do not create a new page-specific CSS file or image folder unless the project structure is intentionally changed later.
